# Приют для кошек «Мурлыка»

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Учебный многостраничный сайт приюта для кошек. Реализован процесс поиска дома для питомцев, каталог с фильтрами, страницы кураторов и формы для волонтёров.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён **локально** из папки `vendor/bootstrap/` (без использования CDN).
Используются файлы:
- `vendor/bootstrap/css/bootstrap.min.css`
- `vendor/bootstrap/js/bootstrap.bundle.min.js`

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог кошек с фильтрами;
- `product.html` — страница кошки (характеристики, отзывы, калькулятор);
- `order.html` — форма «Предложить помощь»;
- `curators.html` — каталог кураторов;
- `contacts.html` — контакты приюта;
- `css/custom.css` — кастомные стили;
- `js/main.js` — скрипты (валидация, калькулятор, кнопка наверх);
- `vendor/bootstrap/` — локальные файлы фреймворка.

## Реализованные Bootstrap-компоненты

- `navbar` (с выпадающим списком `dropdown`);
- `card` (карточки питомцев и кураторов);
- `btn` (все варианты кнопок);
- `badge` (статусы кошек);
- `alert` (информационные сообщения);
- `modal` (вопрос куратору);
- `carousel` (истории спасения);
- `accordion` (FAQ);
- `breadcrumb` (хлебные крошки);
- `form-control`, `form-select`, `input-group`, `form-check` (все формы);
- `table` (характеристики кошки);
- Сетка: `container`, `row`, `col-*`, `g-*`.

## Самостоятельные доработки

1. Локальное подключение Bootstrap без CDN.
2. Sticky-фильтры в каталоге (`position: sticky`).
3. Кастомный JS: калькулятор расходов на содержание кошки.
4. Валидация форм через JS (стилизация `was-validated`).
5. Кнопка «Наверх» с плавной прокруткой.
6. БЭМ-модификаторы и адаптивная сетка карточек.
